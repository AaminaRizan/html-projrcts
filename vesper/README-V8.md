# VESPER V8 — offset collage + watch construction

Changes from V7:
- Removed the SVG dial preloader entirely. Homepage appears immediately.
- Three-image editorial collage now has deliberately offset heights, creating stepped vertical placement. Each set still uses aligned crops of one original watch photograph.
- Collage switches to the next watch when hovered. It also cycles on a timer, supports watch name hover, click, keyboard, and touch swipe.
- Replaced redundant second triptych in Look a little closer with the exploded 2D watch-components section from V6, using the actual Chrono XL source assets. Includes Separate, Reassemble, Replay and progress slider. It is illustrative, not a technically accurate disassembly.
- Preserved peach/navy visual styling, catalogue and enquiry functionality.

Open vesper/index.html. No build step required.
